# Node.js 설치 안내

Vite 같은 npm 프로젝트를 실행하려면 **Node.js** 가 필요해요. 한 번만 설치하면 됩니다.

## 1. 다운로드

https://nodejs.org/ko/download 에 접속해서 **LTS** 라고 적힌 버전을 받으세요.
(LTS = 오래 지원되는 안정 버전. "Current" 는 받지 마세요.)

- **Windows**: `.msi` 파일 → 더블클릭 → 계속 "다음" → 설치 완료
- **macOS**: `.pkg` 파일 → 더블클릭 → 계속 "계속" → 설치 완료

## 2. 에디터 완전히 껐다 켜기

설치가 끝나면 Antigravity / VS Code 를 **완전히 종료** 했다가 다시 여세요.
창만 닫는 게 아니라 앱 자체를 끝내야 해요 (macOS 는 `Cmd+Q`, Windows 는 창 모두 닫기).

## 3. 다시 Go Live

프로젝트 폴더를 열고 상태바의 **Go Live** 를 다시 누르면 됩니다.

---

### 그래도 안 되면

- Windows 에서 "관리자 권한" 을 묻는 창이 뜨면 "예" 를 누르세요.
- 설치 중 에러가 났다면 컴퓨터를 재시작한 뒤 다시 설치해보세요.
- 그래도 안 되면 터미널 패널의 "Go Live" 탭 내용을 캡처해서 선생님께 보내주세요.
